# Whack-A-Mole-Game
This is a standard Whack-A-Mole game where you have to hit the moles that pop up while avoiding the bombs. The moles gradually pop up faster, but the number of bombs gradually increase. Try to achieve the highest score possible! This is a school project where I had to use Java Swing and improve on an AI generated starter code and add/remove components so that it aligns to my vision of the game.

The requirements of the game were:
- proper collision
- effective use of buttonListener and mouseListener
- at least one abstract class(es)
- use of files and GUI design
